# สถาปัตยกรรมและฟังก์ชัน Google Apps Script — THAI WSK 2026

## รายชื่อฟังก์ชันหลักในระบบ

### 1. `setupSystem()`
- เปิด Spreadsheet ID: `10uaEo5pVJ3hDGeLixOnPsDT60WQtqVmSPXPS4FJnuN8`
- สร้างแผ่นงานทั้ง 7 แผ่นหากยังไม่มี
- สร้างหัวคอลัมน์ สีพื้นหลัง `#4B267D` (ม่วงเข้ม) ตัวอักษรสีขาว `#FFFFFF`
- Freeze แถวที่ 1
- ปรับความกว้างคอลัมน์อัตโนมัติ
- ย้ายแผ่น `ADMIN_CONTROL` ไปไว้ท้ายสุดเสมอ
- บันทึกการติดตั้งลง `SYSTEM_LOG`
- **ปลอดภัย:** หากรันซ้ำจะไม่ลบข้อมูลเดิมที่บันทึกไว้แล้ว

### 2. `getPublicConfig()`
- อ่านการตั้งค่าจากแผ่น `ADMIN_CONTROL`
- แปลงประเภทข้อมูลเป็น boolean หรือ number อัตโนมัติ
- ส่งเฉพาะค่าสาธารณะที่จำเป็นแก่ Frontend ป้องกันการรั่วไหลของข้อมูลลับ

### 3. `searchScore(queryName, verificationCode)`
- ทำการ Normalize ชื่อภาษาไทย ตัดคำนำหน้า (นาย, นาง, นางสาว, เด็กชาย, เด็กหญิง, ด.ช., ด.ญ.)
- ตรวจสอบ `Verification_Code` เพื่อป้องกันการสุ่มดูข้อมูลผู้อื่น (PDPA)
- ส่งคืนผลการสอบ คะแนนเต็ม ร้อยละ ผลการประเมิน และระดับเหรียญรางวัล

### 4. `searchCertificate(queryName, verificationCode)`
- ค้นหาข้อมูลเกียรติบัตร
- ตรวจสอบสถานะ `READY`
- ส่งคืน URL หรือ File_ID สำหรับดาวน์โหลด

### 5. `syncFormResponses()`
- อ่านแผ่นคำตอบของ Google Forms ตามชื่อแท็บที่ระบุใน ADMIN_CONTROL
- คำนวณคะแนนและเกณฑ์เหรียญรางวัลลงในแผ่น SCORES

### 6. `onOpen()`
- เพิ่มเมนูคำสั่งลัดบนแถบเมนู Google Sheets
  - ติดตั้งฐานข้อมูลระบบ
  - ตรวจสอบการเชื่อมต่อ
  - ซิงก์คะแนนจาก Google Forms
  - ตรวจสอบสถานะระบบ
